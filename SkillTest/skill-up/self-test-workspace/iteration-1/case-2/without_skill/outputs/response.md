## Benchmark 评测自测 · 共 6 题

**第 1 题【记忆】**
Benchmark 评测体系的“四要素”是哪四个？每个用一句话说明它的职责。

**第 2 题【理解】**
你们团队按公开榜单第一名选了模型，落到自己的客服业务链路上表现却对不上。为什么会出现这种“选型错位”？模型层 Benchmark 和应用层 Benchmark 的区别是什么，为什么工程重心要放在应用层？

**第 3 题【理解】**
“界定 → 衡量 → 改进”三个阶段分别做什么？其中“数据飞轮”是怎么运转的，为什么说它能让黄金数据集成为“越用越厚的数据资产”？

**第 4 题【应用】**
假设你要评测一个客服 Agent，有三个需求：
- ① 验证回复中的订单号格式是否正确
- ② 判断回复的语气是否友好、内容是否全面
- ③ 判断回复在某个专业领域（如医疗报销政策）的表述是否准确，模型裁判信不过

这三个需求分别该用哪型评分器？各自的判断依据是什么？如果落到 Promptfoo 里，①② 大致能用哪类断言指标？

**第 5 题【分析】**
你们团队的三个不同需求，分别该选什么评测工具？说明理由：
- ① 专门评测自研 MCP Server 与 Agent 的交互
- ② 团队全部用 Python + pytest 生态，要覆盖多轮/多模态/MCP 的全家族指标
- ③ 已深度使用 LangChain/LangGraph，且上线后需要生产监控 + 在线评测

**第 6 题【评价】**
团队用 Promptfoo 搭了自动化评估，CI 里全绿、通过率 95%，结果上线后用户投诉不断。从“评测方法四件套”和 Benchmark 的“劣势与边界”角度分析：这套评估可能缺了什么？你会怎么补？
