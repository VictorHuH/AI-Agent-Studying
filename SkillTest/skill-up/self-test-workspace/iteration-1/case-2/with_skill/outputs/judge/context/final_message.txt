## 📝 Benchmark 评测自测（6 题）

**第 1 题**（理解）
传统软件有单元测试，为什么这套"equals 断言"的思路在 LLM 应用里直接失效？笔记把"改了不知道变好还是变坏"的根因归纳为三条，请说出其中**至少两条**，并用一句话解释"评估驱动开发"是什么意思。

**第 2 题**（记忆）
Benchmark 分哪两层？请分别说出这两层的**评测对象**和**核心价值**各是什么。为什么按公开榜单选出来的模型，落到自己业务场景上表现可能对不上？

**第 3 题**（理解）
评测流程的三阶段是什么？请重点讲讲"**数据飞轮**"是怎么转起来的——从"记录日志"到"黄金数据集成为越用越厚的资产"，中间每一步发生了什么？

**第 4 题**（应用）
你负责一个客服 LLM 应用，有三个断言需求，请为每个需求选择评分器类型（代码型 / 模型型 / 人工型），并说明选择依据：
- (a) 输出必须是合法 JSON，且包含 `order_id` 字段
- (b) 回复语气是否友好、周到（有无数种正确说法）
- (c) 涉及退款政策的回复是否符合公司法务合规要求（需领域专家把关）

**第 5 题**（应用）
用 Promptfoo 评测一个 Agent，你除了想知道"任务最终成没成"，还想验证以下三件事，分别可以用哪些断言/指标实现？（每条至少给出一个具体指标名）
- (a) Agent 是否**按预期顺序**先调用了 search 工具再调用 write 工具
- (b) Agent 是否**真的读取了** SKILL.md 文件
- (c) 最终输出符合 `output_schema` 强制的 JSON 结构

**第 6 题**（评价）
你们团队已用 LangGraph 开发，需要一套"离线评测 + 线上生产监控 + 人工标注"全生命周期的方案，且因数据合规必须支持自托管。
- (a) 在 LangSmith / Langfuse / Arize Phoenix / Braintrust 中你会选哪个？说明理由，并说出被你排除的某两个工具各自的定位特点；
- (b) 笔记指出 Promptfoo 这类纯评测框架有哪两条明显的"边界/劣势"？
