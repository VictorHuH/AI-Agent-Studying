# 工具录入学习库

## 何时用
用户在工作中调研/使用了某个工具，想把它整理进学习仓库。典型触发语：
- "我调研了 XX，整理进笔记"
- "把 XX 录入工具"
- "把 XX 写成教程，同步到路线和总结"
- "记录一下这个工具"

**范围限定**：本 skill 只录入【工程实践】类工具（工作中用到、非学习路线节点），归入「工程实践补充」+「Popular Tools」。
若用户是在记录【学习路线】主题（如学完某个新概念要更新 当前进度/五阶段路线），那是另一套流程，不用本 skill。

## 前置
- 学习仓库根目录：`c:\Users\Administrator\Desktop\AI\Studying`
- 四个落点：
  1. **教程**：根目录 `NN-工具名.md`（NN = 现有最大编号 +1，读 `00-学习路线总览.md`「已学进度详情」的笔记列表，或 Glob `NN-*.md` 取最大值 +1）
  2. **路线索引**：`00-学习路线总览.md` 的 `## 🔧 工程实践补充` 节
  3. **速查总结**：`AI Studying.md` 的 `## Popular Tools` 节
  4. **记忆**：`C:\Users\Administrator\.claude\projects\c--Users-Administrator-Desktop-AI-Studying\memory\learning-progress.md` 末尾「工程实践补充」块
- 用户给的素材可能乱码/口语/缺失，需解码清洗为规范中文

## 步骤
1. **定编号**：读 `00-学习路线总览.md` 笔记列表或 Glob `NN-*.md`，取现有最大编号 +1 作为 NN
2. **建教程 `NN-工具名.md`（全量）**：参考 `references/templates.md` 的「教程骨架」。结构 = 头部(日期+`衔接 [[NN-相关]]`+关键词) → 核心认知(一句话定位) → 问题/本质 → 原理/核心机制 → 怎么跑的 → 命令用法 → 实测数据(若有) → 官方 benchmark(若有) → 劣势边界 → 同类对比 → 收尾+连接已学 → 参考资料。归"工程实践调研，非学习路线节点"
3. **更新 `00-学习路线总览.md`（极简）**：在「🔧 工程实践补充」节加 `### 工具名（一句话定位）`，**只写 3 行**：概念 + 适用场景(含收益边界) + 详见指针。更新文件顶部「最后更新」日期。在「已学进度详情」笔记列表末尾加 `NN-工具名.md（工程实践调研，非学习路线节点）`
4. **填充 `AI Studying.md`【Popular Tools】（中等密度）**：加 `### 工具名` 子节，参考 `references/templates.md` 的「速查骨架」。密度介于教程与 00 之间
5. **同步 `learning-progress.md` 记忆**：在文件末尾「工程实践补充（非学习路线节点）」块加一条（若无此块则新建，置于「相关：[[user-profile]]」之前）

## 密度纪律（关键，三处不重复）
三层递进，**00 只放指针指向另两处**：

| 位置 | 密度 | 内容 |
|---|---|---|
| `NN-工具名.md` 教程 | 全 | 完整机制+实测数据+benchmark+劣势+同类+连接已学 |
| `AI Studying.md` Popular Tools | 中 | 定义+核心+命令表+精简实测+劣势+同类表 |
| `00-学习路线总览.md` 工程实践补充 | 简 | 概念+适用场景+详见指针（3 行） |

## 注意（Rule 护栏）
- **工程实践归类**：录入工具归「工程实践补充」，**不是学习路线节点**。绝不改「当前进度」「📊 五阶段路线」「🚀 推荐学习顺序」「💡 核心认知」「📚 已学进度详情」中的学习路线内容；绝不往 MEMORY.md 索引钩子加该工具
- **连接已学**：把工具锚定到已学概念（Skill / Prompt Rule / Agent / Harness / MCP / FC / LangGraph …）当"产品级组装"来讲，而非新概念。教程头部用 `衔接 [[NN-xxx]]` 连最近相关教程
- **数据核验**：用户素材若乱码/缺失/可疑（如表格行重复标注同一组别），先解码，**有歧义的数据点必须标出请用户确认**，不要替用户猜（参考 Ponytail 案例：一般任务某行实验组别乱码重复，按数据特征修正并提示用户核验）
- **清洗输出**：解码乱码为规范中文，绝不复现 mojibake
- **记忆不动学习路线**：learning-progress 记忆只加在末尾「工程实践补充」块，标注"非学习路线节点，不影响上面学习路线追踪"，不动主体学习进度追踪
