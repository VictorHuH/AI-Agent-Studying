# 布鲁姆认知层次与出题示范

> 自测出题时，按下面 6 个层次混合出题，避免全出死记硬背（记忆层）的题。
> 越往下越考验"真懂"，能查出一知半解。
> 示范统一用 RAG 举例，方便对照。

## 1. 记忆（Remember）-- 能回忆起事实
问"是什么"。最简单，别出太多。
- 示范：RAG 的经典三步流程是什么？

## 2. 理解（Understand）-- 能用自己的话解释
问"为什么"，考有没有真懂。
- 示范：为什么 RAG 要走语义检索而不是关键词匹配？

## 3. 应用（Apply）-- 能在新场景用上
给个新场景让用户操作，考迁移能力。
- 示范：你的 RAG demo 里，如果把简历换成一篇 30 页的论文，Chunking 策略要怎么调？

## 4. 分析（Analyze）-- 能拆解、对比、找关系
问"区别/联系/边界"，最能查出混淆。
- 示范：Function Calling 和 Agent 的边界在哪？给一个"该用 FC 不该用 Agent"的场景。

## 5. 评价（Evaluate）-- 能判断好坏、做选择
问"哪个更好/有什么问题"，考批判性。
- 示范：某份 RAG 答案用了 rerank 但 Hit@3 仍只有 60%，可能的原因有哪些？你最怀疑哪个？

## 6. 创造（Create）-- 能组合设计新方案
问"怎么设计"，最高阶。
- 示范：设计一个能记住用户偏好的客服 Agent，三层记忆分别怎么用？

---

## 出题配比建议
记忆 : 理解 : 应用 : 分析 = 2 : 3 : 3 : 2
评价、创造按需各出 0-1 题（难度高，挫败感强，慎用，别拿来打击信心）。

一条铁律：**一个考点最多一道题**，避免重复轰炸同一个知识点。
