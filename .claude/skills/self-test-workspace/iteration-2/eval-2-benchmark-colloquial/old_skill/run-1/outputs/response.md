**第 1 题【记忆】**
应用层 Benchmark 的整体评测流程是哪三个阶段？其中改进阶段有一个让黄金数据集"越用越厚、越用越准"的机制，它叫什么、是怎么运转的？

**第 2 题【理解】**
笔记里把 LLM 应用的一种病叫"选型错位"：按公开榜单选了模型，落到自己业务场景表现却对不上。用你自己的话说说：为什么会对不上？背后的根因有哪几条？

**第 3 题【应用】**
你在给一个 RAG 客服系统配评分器，手上有三个断言需求：
- (a) 回答必须是合法 JSON，且包含 `order_id` 字段
- (b) 回答语气是否礼貌、有没有答非所问
- (c) 一条金融合规话术是否合规——只有法务专家说得清

这三个分别该用代码型、模型型还是人工型评分器？关键是说出你每一步的**判断依据**（提示：笔记里有一条使用准则）。

**第 4 题【应用】**
你给公司内部的订票 Agent 新加了一个"改签"工具，担心这次改动把原来"查票 → 下单"的流程悄悄搞坏。用笔记里 Agent 评测的思路说说你会怎么设计回归测试：
- 测的对象是什么（Agent 评测为什么说"测系统不测模型"）？
- 你会用哪些 trajectory 类的断言？各自卡什么点？

**第 5 题【分析】**
Promptfoo 和 Langfuse 在笔记里被归为两类不同物种。对比一下：
- 两者的核心能力边界差在哪（各自的强项和"完全没有"的东西）？
- 什么情况下光用 Promptfoo 就够，什么情况下"只有 Promptfoo 不够用"？
- 如果需求就只是"给 RAG 管道做专项评测"，还有没有更对口的选择？

**第 6 题【评价】**
某团队上了全自动评估：黄金集 30 条 + `llm-rubric` 评分 + CI 门禁，跑分一直 95%+，但上线两周后用户投诉激增。结合笔记"劣势与边界"一节：
- 列出至少两个可能的原因；
- 说说你最怀疑哪一个、为什么，以及你会怎么补救。
