## 第 3 题【应用】

评分器三型的选择准则是"能编码→代码型；能描述→模型型；都不行→人工型"。判断下面三个业务断言各该用哪一型，并说明理由：

1. 客服 Agent 的输出必须是合法 JSON，且必须包含 `order_id` 和 `refund_amount` 两个字段

3. 一份给高管看的并购法律意见书是否专业可靠

## 第 4 题【应用】

你负责一个 RAG 系统的评测，用 Promptfoo 跑出两类故障（假设都有黄金数据集可用）：

- **故障 A**：检索阶段漏掉了关键文档，答案缺少依据
- **故障 B**：检索到了正确文档，但生成的答案与文档内容不符（有编造）

针对 A、B 两种故障，你分别会重点看哪些评测指标来定位问题？为什么一个指标不够、要分检索/生成两阶段评测？

---

## 第 5 题【分析】

笔记里说 eval harness（评测框架）有五大功能，其中两个是"**隔离环境（每次干净启动）**"和"**同一任务跑 k 次 → 算 pass@k**"。传统软件的单元测试既不需要每次干净启动隔离环境，也从来不跑 k 次取成功率。

**为什么到了 LLM 应用评测这两件事就变得必要了？** 背后的共同根因是什么？
