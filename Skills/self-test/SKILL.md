# 学习自测出题

## 何时用
用户想用问答方式复习已学内容。典型触发语：
- "考我 RAG"
- "自测一下 Agent"
- "出 3 道题检验 Prompt Engineering"
- "检验一下我学没学会 MCP"

## 前置
- 笔记根目录：`c:\Users\Administrator\Desktop\AI\Studying`
- 用户没指定主题时，先列出可考的笔记文件让他选
- 找不到对应笔记时，直接问用户要考哪个主题，别瞎猜

## 步骤
1. **列考点**：运行 `python scripts/extract_topics.py <笔记路径>`，提取该笔记的所有标题作为考点清单
2. **确认范围**：把考点清单给用户看，问"要考全部还是挑某几节？出几道题？"
3. **按认知层次出题**：参考 `references/bloom_taxonomy.md` 的认知层次（记忆 / 理解 / 应用 / 分析……），混合出题，别全出死记硬背的题
4. **先问后判**：出完题先不公布答案，等用户逐题作答
5. **判分 + 讲透**：用户答完后逐题判分；错的题讲清楚为什么错、正确答案是什么、对应笔记的哪一节

## 注意（Rule 护栏）
- 一个考点最多出一道题，避免重复轰炸
- 出题后**绝不**先透露答案
- 用户答错时，先讲思路再给答案，别直接甩结论
- 用户回答模糊时，追问澄清，别擅自假设对错
- 笔记里没有的内容，明确说"笔记未涉及"，不要编题
