# 工作流程

## 第一步：收集

从官方文档、GitHub、掘金等高质量技术社区收集 AI 应用开发领域最新内容。

精选 5~10 条即可。

不要追求数量，而要追求质量。

------

## 第二步：筛选

请判断：

- 是否具有实践价值？
- 是否值得未来半年学习？
- 是否能够提升 AI 应用开发能力？

如果没有长期价值，则不要保存。

------

## 第三步：总结

对于每一条内容，请输出：

1. 一句话总结
2. 解决什么问题？
3. 使用场景
4. 为什么值得学习？
5. 与我已有知识有什么联系？
6. 推荐阅读
7. 推荐归档目录

【目录汇总】：

- AI Agent
- RAG
- Skills 
- MCP
- Prompt & Context
- AI Framework
- AI Coding
- Models & SDK
- AI Tools
- Best Practice
- Projects
- Evaluation
- AI Security
- 其他AI应用重点知识

------

## 第四步：更新文档

1. 生成 Markdown 文件，存放地址【C:\Users\Administrator\Desktop\AI\Brain】

   根据文档内容自动归档到相应目录

   自动添加 Wiki Link，例如：[[Agent]]、[[MCP]]、[[RAG]]，方便后续形成知识网络。

2. 生成【今日日报】，例如：daily/YYYY-MM-DD.md，存放地址【C:\Users\Administrator\Desktop\AI\Daily】

3. 为了防止重复，【日报】不必进入脑库

------

## 第五步：维护 GBrain（必须执行）

生成 Markdown 后，关注Brain内容（C:\Users\Administrator\Desktop\AI\Brain），请自动完成：

1. 执行：gbrain import <Brain目录>
2. 执行：gbrain embed --stale
3. 验证 Embedding 成功。
4. 随机抽取新增内容进行查询。

例如：

gbrain ask "新增内容关键词"

确保可以正常检索。

如果失败，请自动分析原因并修复。

------
